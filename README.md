# Caso 1 — Alerta temprana por altas temperaturas

Proyecto académico (DSY1105 · Desarrollo de Aplicaciones Móviles, Duoc UC).

App Android con Jetpack Compose para consultar condiciones ambientales de
galpones, recibir alertas tempranas y revisar historial. Datos simulados,
persistencia local con Room y notificaciones.
